# per aspera at Hogwart

Dwa fanowskie projekty 3D o Hogwarcie, zbudowane w Three.js, po polsku.

| Folder | Co to jest | Uruchomienie |
|---|---|---|
| [`hogwarts-atlas/`](hogwarts-atlas/) | **Atlas magicznego świata**: interaktywna wycieczka 3D po zamku i okolicy, z porami dnia i pogodą | `cd hogwarts-atlas` → `node server.mjs` → http://127.0.0.1:4173 |
| [`hogwarts-rpg/`](hogwarts-rpg/) | **Szlaki Magii**: grywalny rozdział RPG z zaklęciami, eliksirami, talentami i zadaniami | `cd hogwarts-rpg` → `npm start` → http://127.0.0.1:4174 |

Oba projekty działają bez instalowania pakietów: Three.js, fonty i tekstury są dołączone lokalnie. Gotowe strony leżą w katalogach `dist/`. Nie otwieraj ich dwuklikiem (`file://`), tylko przez serwer.

Szczegóły znajdziesz w README każdego projektu.

---

Projekt fanowski, niekomercyjny. Harry Potter i powiązane nazwy należą do ich właścicieli.
